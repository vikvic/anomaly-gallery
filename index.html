Ops Lab

Clone and removal measured on three still lifes, with the altered region marked and per-op timings.

Every painting is public domain. Nothing is generated: each anomaly is a deterministic pixel operation over the painting's own paint, so the answer key is exact by construction and the brushwork, palette and varnish survive the edit intact.

Face landmarks via MediaPipe (478 points) locate the features; everything after that is plain canvas geometry.
