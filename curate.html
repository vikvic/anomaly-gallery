Asset Curator

Runs face detection and blob targeting over every downloaded painting, marks which ops each one can actually support, and writes the result back into the manifest. Click any card to include or exclude it by hand.

load assets/manifest.json to begin

Green outline = face detected (supports rictus, drift, elongate, and can donate an eye or mouth). Amber circle = blob target found (supports graft). A painting with neither is dead weight — drop it.

Export writes usable, hasFace and normalised blob coordinates into each entry, so the game never runs a distance transform at load time and never picks a painting whose detection fails.
